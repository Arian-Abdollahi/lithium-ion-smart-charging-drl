# Original uploaded attention notebook

`original_wattention.ipynb` preserves the source code of the 30-cell notebook
uploaded as `wattention (28).ipynb`. Output cells and ephemeral execution
metadata were cleared to keep the Git history compact and avoid accidentally
publishing training outputs as research evidence.

**Run the importable modules/CLI instead of executing this notebook from top
to bottom.** Some notebook cells install packages interactively, use absolute
Kaggle dataset paths, and refer to external `.mat` data, prior trained weights,
replay buffers and monitor CSVs that were not included in the upload.

The main results in the repository README are taken from the **thesis PDF**,
not from any notebook cell output. For exact code-cell provenance, see
[`../docs/source-provenance.md`](../docs/source-provenance.md).
